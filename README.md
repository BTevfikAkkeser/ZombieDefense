## About

ZombieDefense is a mobile game made in Unity, where the player defends against waves of zombies. The goal is to survive as long as possible by strategically placing defenses, upgrading abilities, and managing resources under increasing difficulty.

---

## Features

- Multiple zombie waves with increasing difficulty  
- Upgradable weapons or defense systems (if applicable)  
- Health, scoring, and wave management  
- Simple, intuitive mobile controls  
- Optimized for mobile performance  

---

## Gameplay

1. The player starts with a basic weapon or defense setup.  
2. Zombies spawn in waves and try to reach/attack the player or base.  
3. Player must eliminate or block zombies using available defense tools.  
4. Between waves, the player can upgrade defenses / recover / prepare for stronger waves.  
5. Game ends when the player's health reaches zero or defenses are overwhelmed.
